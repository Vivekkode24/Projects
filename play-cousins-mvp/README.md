# Play Cousins Collective MVP

## Quick start
1. `cd play-cousins-mvp`
2. `npm install`
3. `npm run dev`

## Deploy
- Push to GitHub.
- Import repo in Vercel.
- Build command: `npm run build`

## Notes
- Uses demo data in `lib/demoData.js` for safe presentation.
- Supabase can be connected later by replacing demo arrays with DB calls.
